# Insight Cycle

Eagle Insight Platform is retired as a commercial offering; this describes the Insight Cycle as it operated, as reference documentation for the assessment model the Eagle Framework produced. triNetra's current commercial offer is Framework Building — see [trinetrarv.com/engage](https://trinetrarv.com/engage).

---

## What an Insight Cycle Was

An Insight Cycle began when the assessed entity submitted an Input Manifest. It closed when the Assessment Report and all comparative deliverables for that cycle were delivered.

The deliverables produced within a single Insight Cycle depended on the assessment's intelligence domain:

| Domain | Inputs | Deliverables |
|---|---|---|
| Organisation Intelligence | One Input Manifest submission | Assessment Report, Eagle Score, maturity level classification |
| Alignment Intelligence | Input Manifests for each assessed portfolio company | Assessment Report per company, Alignment Score, Gap Analysis, Structural Divergence Analysis relative to the Reference Manifest |
| Portfolio Intelligence | All Alignment Intelligence inputs | All Alignment Intelligence deliverables plus cross-portfolio structural pattern analysis, correlated risk map, and portfolio structural evolution tracking |

---

## Cycle-to-Cycle Continuity

The Insight Cycle model compounded in value across cycles. The Reference Manifest carried forward and could be versioned as the investment thesis evolved. Historical Eagle Scores and maturity levels from prior cycles formed the basis for Evolution Analysis: tracking whether the system was improving, stable, or deteriorating structurally over time.

A client who ran three consecutive Insight Cycles gained a structural history: what the system was, what changed, what improved, and what structural conditions persisted despite intervention.
